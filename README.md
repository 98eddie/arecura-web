# ARECURA — 웹

App Store 심사가 요구하는 **지원 URL**과 **개인정보처리방침 URL** 을 위한 정적 페이지입니다.

| 주소 | 무엇 |
|---|---|
| `/` | 소개 |
| `/support.html` | 문의 안내 |
| `/privacy.html` | 개인정보처리방침 |
| `/terms.html` | 이용약관 |

## ★손으로 고치지 마세요

`privacy.html` 과 `terms.html` 은 **생성물**입니다.
앱 안에 표시되는 본문과 **같은 원본**(앱 저장소의 Swift 소스)에서 스크립트로 뽑습니다.
여기서 고치면 앱과 웹이 갈라지고, 그게 곧 심사에서 지적받는 자리입니다.

고칠 일이 생기면 앱 저장소에서 원본을 고치고 `scripts/publish-site.sh` 로 다시 올립니다.
